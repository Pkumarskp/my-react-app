## Interview Answer Template (For Any Question)

**1. CLARIFY (30 seconds)**
> "Just to clarify, are we talking about [scenario]? And what's the scale - [number] users?"

**2. APPROACH (1 minute)**
> "I'd approach this by first considering [constraint]. Given that, I'd use [solution] because [reason]."

**3. IMPLEMENTATION (2-3 minutes)**
> "Here's how I'd code it..." [Show code or pseudocode]

**4. TRADE-OFFS (1 minute)**
> "This approach is good for [case] but would struggle with [case]. If we needed [different constraint], I'd instead [alternative]."

**5. EXAMPLE (1 minute)**
> "For instance, in Aura Market, I [specific example from your project]."

**Total: ~6-7 minutes per question**

---

## Red Flags to Avoid

❌ **"I don't know"** → Instead: "I haven't done that specifically, but my approach would be..."

❌ **Vague answers** → Always give specific examples with code

❌ **No follow-up questions** → Ask: "How many users?" "What's the latency requirement?"

❌ **Ignoring security** → Always mention: auth, validation, errors

❌ **Not thinking about scale** → Consider: 10 users? 1M users? 1B records?

❌ **Coding without planning** → Explain your approach before writing code

---

## Green Flags to Show

✅ **Ask clarifying questions** - "Can you tell me more about the requirements?"

✅ **Consider trade-offs** - "This is simple but wouldn't scale. For enterprise, I'd..."

✅ **Think step-by-step** - Explain your thinking as you go

✅ **Show actual code** - Not pseudocode, real working code

✅ **Discuss edge cases** - "But what if the product is out of stock?"

✅ **Mention testing** - "I'd write tests for this..."

✅ **Reference your project** - "This is similar to how I built [feature]"
